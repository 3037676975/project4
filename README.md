# 🤖 AI-CS Enterprise

企业级 AI 智能客服 SaaS 平台。

基于 KnowFlow-v24 核心项目，并融合 AI-CS 智能客服系统能力。

## ✨ 核心能力

- 🤖 AI 智能客服
- 📚 RAG 企业知识库问答
- 🧠 Agent 智能体工作流
- 🔌 MCP 工具调用
- 🎫 智能工单系统
- 🏢 多租户 SaaS 架构
- 🐳 Docker 一键部署

## 🛠 技术方向

### AI

### Platform
