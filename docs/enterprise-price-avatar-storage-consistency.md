# 企业端价格、客服头像与知识库存储一致性

这次修复把三个容易产生“后台已改、企业端还显示旧值”的地方统一成同一套规则。

## 1. 套餐价格

- 企业端套餐卡固定按“分”转换成两位小数展示，例如 `10` 分显示 `¥0.10`、`29900` 分显示 `¥299.00`。
- 企业打开“套餐与账单”时、窗口重新获得焦点时，以及页面停留期间会重新拉取平台最新套餐。
- 点击购买时会在创建订单前再次读取最新套餐价格。
- 如果平台刚刚改价，企业端会先刷新价格并要求重新确认，不会拿旧展示价格直接进入付款。
- 创建订单后再次校验 `order.amountCents === 当前套餐 monthlyPriceCents`，不一致时阻止继续付款。

## 2. 客服头像

官网、企业“网站 Widget”预览、外部网站 `widget.js` 收起后的悬浮按钮统一使用：

`/brand/support-agent.jpg`

不再使用旧的 `support-agent-v3.jpg`。

## 3. 知识库存储额度

- 每个企业继续按当前订阅套餐的 `storage_quota_bytes` 独立限额。
- 新增 `knowledge_documents.storage_bytes`，新上传文档按真实原文件字节数计入企业存储。
- 历史文档迁移时以 `char_count * 2` 作为兼容估算值。
- 企业侧边栏“知识库”直接显示“剩余空间”。
- 知识库页面显示：当前套餐、已用、总额度、剩余空间和使用百分比。
- 超级管理员租户列表同步显示每家企业的已用空间 / 套餐额度。

## 构建保护

`scripts/apply-enterprise-consistency-patch.mjs` 会在正式构建前执行，并对关键源码锚点做强校验。若以后源码结构变化导致价格、存储或头像补丁无法安全应用，构建会直接失败，而不是悄悄发布不一致版本。
