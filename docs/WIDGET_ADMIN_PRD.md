# Project4 Widget 管理中心 PRD

## 目标

将网站右下角 AI 客服 Widget 从固定代码升级为可配置 SaaS 组件。

## Phase 2.7 范围

### 管理入口

/admin/widget-settings

### 配置能力

#### 1. Widget 开关

- 开启客服窗口
- 关闭客服窗口

#### 2. 基础信息

- 客服名称
- 欢迎语
- 客服头像

#### 3. 外观配置

- 主题颜色
- 悬浮位置
- 圆角风格
- 按钮样式

#### 4. 会话模式

- AI 自动接待
- AI + 人工协同
- 纯人工客服

#### 5. 快捷问题

管理员可以配置常见入口：

- 产品介绍
- 价格咨询
- 联系销售
- 技术支持

## 数据流

管理员配置

↓

WidgetSettings

↓

WidgetManager

↓

网站访客客服窗口

## 验收标准

- 管理员修改配置后 Widget 可以读取
- 默认配置保证旧页面正常运行
- 配置异常时自动回退默认值
- 不影响已有聊天 API
